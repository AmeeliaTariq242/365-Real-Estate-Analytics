# 365 Real Estate Analytics

An interactive real estate analytics and property valuation platform built using Python, Streamlit, Pandas, and Machine Learning.

## Overview

365 Real Estate Analytics explores property transaction data and provides insights into real estate market trends. The project features an interactive dashboard, transaction analysis, and machine-learning-based property valuation.

## Features

- **Market Overview:** View transaction statistics and key market indicators.
- **Property Valuation:** Estimate property values using a trained machine learning model.
- **Transaction Analysis:** Explore property transaction data and price distributions.
- **Interactive Dashboard:** Navigate between Valuation Studio, Market Explorer, and About the Model.
- **Data Visualization:** Explore real estate market patterns through charts and visual summaries.

## Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Joblib
- Jupyter Notebook

## Model Information

The application uses a trained machine learning model to support property valuation. Estimates are intended for decision support and should not be treated as formal property appraisals.

## Disclaimer

This project is intended for educational and analytical purposes. Valuation estimates depend on the available dataset and model performance and may not reflect current market prices.
